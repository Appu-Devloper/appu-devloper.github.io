Modbus Scanner

Automatic Modbus TCP/RTU Scanner

Public

An automatic Modbus discovery tool for the ESP32-P4 Nano that finds responding devices and reads raw register values over TCP or RS-485 RTU.

  • Ethernet priority with Wi-Fi fallback and static IP fallback when DHCP is unavailable.
  • Multi-unit discovery, including multiple responding unit IDs behind the same TCP endpoint.
  • Readable USB serial scan summaries with responding unit IDs and register values.
Platform: Waveshare ESP32-P4 Nano Configuration: Firmware settings via ESP-IDF
ESP32-P4 ESP-IDF Modbus TCP/RTU RS-485 Ethernet / Wi-Fi
